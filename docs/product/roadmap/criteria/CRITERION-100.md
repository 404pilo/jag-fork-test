# CRITERION-100: The project board becomes public after the new repository

The GitHub Project of the ai-ready-future organization stays private until the new repository is public. After the new repository becomes public, the Project is linked to it and becomes public. ai-ready-future/jag stays private.

Order: The new repository is created as a private repository. While it is private, the open issues move to it, the board items and the issues are checked, and the second scan runs. Then the new repository becomes public, and after it the board.
