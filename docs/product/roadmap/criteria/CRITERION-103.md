# CRITERION-103: The open issues move to the new repository while it is private

While the new repository is still private, each open issue of ai-ready-future/jag moves to it with gh issue transfer. Closed issues do not move. Before the issues move, the new repository has the same labels and milestones, so that each issue keeps them.

Why: GitHub cannot move an issue from a private repository to a public one.
