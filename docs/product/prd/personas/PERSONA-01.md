# PERSONA-01: Agent builder

The agent builder builds or configures agents, such as coding agents, custom agents, and evaluation harnesses. The agent calls jag; the builder chooses jag, installs it, and pays for the tokens.

Limits: some users cannot send their text to an outside model service, and each query costs model money. Choice criteria: the tool feels like grep, it gives better hits than grep, and it is open source and free.
