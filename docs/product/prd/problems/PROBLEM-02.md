# PROBLEM-02: The flood costs tokens and time

The flood has two costs:

- **Tokens.** A person who builds an agent pays for each token that the agent reads. Search output that does not answer the question is paid waste on each run.
- **Time.** A person who uses an agent, such as a coding agent, waits while the agent reads search output turn after turn before it answers.
