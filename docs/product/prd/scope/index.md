# scope

* [SCOPE-01: Release 1: first public release](SCOPE-01.md) - The first public release of jag: term and question search with setup, file and line, a size limit, two output forms, and a feel like grep.
* [SCOPE-02: Release 2: trust and cost](SCOPE-02.md) - Release 2 shows the cost of a search, says which text leaves the machine, and lets the user measure jag on their own questions.
* [SCOPE-03: Release 3: question without a term](SCOPE-03.md) - Release 3 lets the user ask only a question, with no term.
* [SCOPE-04: Later: local model option](SCOPE-04.md) - A later release adds a mode that keeps all text on the machine, for users who cannot send text out.
* [SCOPE-05: Later: runs where the user cannot install packages](SCOPE-05.md) - A later release lets jag run on a machine where the user cannot install packages, from one download.
* [SCOPE-06: jag builds no search index](SCOPE-06.md) - jag never builds or keeps an index of the folder; each search reads the files as they are.
* [SCOPE-07: jag writes no answers or summaries](SCOPE-07.md) - jag returns source lines only and never writes an answer or a summary in its own words.
* [SCOPE-08: jag has no GUI, web app, or editor plugin](SCOPE-08.md) - jag is a command-line tool only.
* [SCOPE-09: jag has no hosted service and no account](SCOPE-09.md) - jag runs on the machine of the user; there is no jag server and no jag account.
* [SCOPE-10: The held-out score confirms the gain over grep](SCOPE-10.md) - Before release 1, the held-out evaluation run is done and confirms the gain over grep before the README makes an accuracy claim.
