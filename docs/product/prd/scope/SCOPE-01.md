# SCOPE-01: Release 1: first public release

Release 1 is the first public release of jag. It delivers the core value from end to end: a person or an agent asks a question of a folder and gets the few lines that answer it.

Release 1 does not serve users whose text must not leave the machine. This is a known limit.
